# 📅 Sociocom Schedule

Современное веб-приложение для просмотра университетского расписания 81 группы 1 курса специальности "Социальные коммуникации" Факультета философии и социальных наук БГУ, адаптированное под мобильные устройства.

## ✨ Особенности

### Для cтудентов (пользователей)
- PWA-приложение, которое можно установить на iPhone/Android.
- **Умное расписание:**
  - Автоматический скролл к текущему дню.
  - Подсветка сегодняшнего дня.
  - Возможность просмотреть расписание на другие недели.
  - **Наложение событий:** Если пара отменена или назначена контрольная, это отображается прямо в карточке пары.
- **Планер:** Отдельная вкладка со списком всех дедлайнов, экзаменов и зачетов на семестр вперед.
- **UI/UX:** Чистый интерфейс, адаптированный под управление одной рукой.

### Для старосты (Админ-панель)
- **Защищенный вход:** Авторизация через Supabase Auth.
- **Управление расписанием:** CRUD-интерфейс для постоянных пар.
- **События:** Создание разовых событий:
  - ❌ Отмена пары.
  - 🔥 Контрольная / УСР (привязка к паре).
  - ⏰ Дедлайн (с точным временем).
  - 🎓 Экзамен / Консультация / Зачёт (вне сетки звонков).
- **Справочники:** Управление списком предметов для унификации данных.

## 🛠 Технологический стек

- **Frontend:** Next.js 16 (App Router), React Server Components.
- **Styling:** Tailwind CSS.
- **Logic:** date-fns (работа с датами), TypeScript (типизация).
- **Backend / DB:** Supabase (PostgreSQL, Row Level Security).
- **Deployment:** Vercel.
